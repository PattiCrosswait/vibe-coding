## Overview

This repository includes three vibe coded apps that I had created:
     Passive-Aggressive Sticky Note Maker: Pick a situation (dishes, parking, thermostat) and a politeness-to-rage slider; it drafts the note on a yellow sticky.
     Brain Dump Timer: 5-minute free-write with a gentle fade-out of the text at the end so you start fresh. Optionally save before it fades.
     Pixel Pet Planner: Complete tasks to feed a pixel creature that evolves over the week.
